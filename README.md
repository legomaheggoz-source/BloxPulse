# BloxPulse

**Roblox Market Intelligence Engine**

BloxPulse is an AI-powered market research and trend intelligence platform for the Roblox ecosystem. It identifies emerging micro-trends, analyzes competitor monetization strategies, and helps developers make data-driven decisions.

## Features

- **Trend Dashboard**: Real-time trending games, CCU tracking, genre distribution
- **Data Collection**: Automated scraping of Roblox official APIs
- **Aurora Solar Light Theme**: Beautiful glassmorphism UI
- **Zero Cost**: Runs on HuggingFace free tier

## Tech Stack

- **Backend**: Python 3.12, FastAPI, SQLite
- **Frontend**: React 19, Vite, Tailwind CSS, Recharts
- **Infrastructure**: HuggingFace Spaces (Docker)

## Data Refresh

Data is automatically refreshed every 6 hours from Roblox official APIs.
